# The agent owns the task while tools own truth and authority

GTM Observability presents one site-aware analytics agent that maintains the user's
goal, plan, progress, and next decision across conversation turns. The agent may
interpret language and choose among bounded tool actions, but validated tool results,
tracking specifications, deterministic verdicts, durable setup operations, and exact
approval checkpoints remain the sources of truth and authority. We reject both a
scripted wizard disguised as chat and an unconstrained model that can invent evidence
or publish changes, accepting the extra contract work so the experience can feel fluid
without weakening measurement or production safety.
