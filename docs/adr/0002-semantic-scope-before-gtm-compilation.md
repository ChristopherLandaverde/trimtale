# Confirm semantic scope before GTM compilation

Navigation intake resolves privacy-filtered observed target groups and records one practitioner-confirmed navigation scope before deterministic code compiles selectors or GTM entities. We reject both flat per-link selection as the durable model and model-authored selectors: grouping is needed to distinguish repeated destinations across header, mobile, and footer regions, while deterministic compilation preserves grounding, idempotency, and safe reuse in large containers.
