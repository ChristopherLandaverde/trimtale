# Publish the reviewed version from the website agent while the portal records it

Status: accepted

Stage 1 keeps setup, exact-version review, and human-approved publication in the
website agent because making the practitioner leave the task for a portal would weaken
the time-to-verified-setup advantage. The signed-in control portal owns identity,
Google authorization, inventory, access, and durable history, but it is not a tag
editor or mandatory publication stop. This requires publication approval to be bound
to the authenticated person and exact displayed version fingerprint, and requires the
resulting operation and receipts to remain consistent across both surfaces.
