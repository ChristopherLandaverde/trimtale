# Change records

Each code-bearing pull request adds one concise Markdown record here. A record explains the user-visible or system behavior being changed, the permanent regression coverage that protects it, verification evidence, and documentation impact.

Use `template.md`. Name records `YYYY-MM-DD-short-description.md`. Records are cumulative project history and should not be deleted when a pull request merges.

Documentation-only pull requests do not require a record. A code-bearing pull request may use one record for one coherent vertical slice; it does not need a record per commit.
